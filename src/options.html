Where to save

Use / for folders inside folders, e.g. Libby/Books. Browsers only let extensions save inside the Downloads folder; to use a different drive or folder, change the browser's own download location in its settings.

File names

Click a variable below to add it. Put optional parts in < >: they are left out when a variable inside is empty, so <{series} {seriesNumber} - >{title} skips the series for standalone books. A / makes a folder, e.g. {author}/{title}. The extension (.epub, .pdf or .acsm) is added for you.

Other

0 means no extra wait. If OverDrive's download server says "too many requests", bookhoard waits a minute and slows down by itself; set a few seconds here if it keeps happening.

Troubleshooting

Errors are always logged. Steps show in the Libby tab's console (F12); file naming shows in the extension's background console. Copy log on the results panel copies all of it, ready to paste into a bug report.
