bookhoard

Where to save

A folder inside your Downloads folder, like Libby or Libby/Books. Leave it blank to save straight into Downloads. To save somewhere else entirely, change your browser's download location.

File names

Click a field below to add it. Anything inside < > is left out when it's empty, so <{series} {seriesNumber} - >{title} only adds the series when there is one. A / makes a folder. The file extension is added for you.

Downloading

Leave this at 0. If OverDrive says "too many requests", bookhoard pauses for a minute and slows down on its own. Raise it only if that keeps happening.

Troubleshooting

Writes each step to the browser console. To share it, click Copy log on the results panel and paste it into a bug report.
